# Yuzuhub home — surface brief

Mode: Experience — visitors browse a real directory of projects and profiles.

## Direction contract

- **THESIS:** A compact author-led directory puts working projects before the owner's portrait; the person is present, but never competes with the work.
- **OWN-WORLD:** Yuzuctus mint `#A6E9D1`, warm cream, deep green-ink, and Nunito. Use thin rules, flat color fields, and the user's original credited artwork. No visual vocabulary carried forward from the rejected hub iteration.
- **STORY:** The visitor sees the project index immediately, gets an accurate Osurea summary and a bounded real preview, scans five concise project entries, then reaches Yuzuctus.fm and distinct Social & Code / Games profile groups.
- **FIRST VIEWPORT:** A 60px utility masthead; a compact mint title band; an immediate split index with Osurea in one short, uncased screenshot row; five compact typographic entries; one restrained OC image, credited. At desktop, the content list remains dominant. On mobile, the image and content stack without requiring a full-screen portrait or an oversized preview.
- **FORM:** Asymmetric editorial directory, not a SaaS hero and not a set of cards. Project rows use names, accurate one-line descriptions, and useful destinations. Profile groups are visibly separate on desktop and mobile.
- **SIGNATURE INTERACTION:** The character art placements receive distinct random OC illustrations on each page load, shuffled without repeats. Language, theme, copy-to-clipboard, and section-current behavior remain functional.
- **MOTION:** Content is visible by default. Only small state transitions; reduced-motion preference is respected.
- **RISK:** A dense index can feel like a changelog. The mint masthead, author art, and one genuine product preview give it authorship without sacrificing scan speed.

## Composition decision

Approved by delegated choice: `.impeccable/mocks/index-first-rail.png`.

The selected structure is the immediate project index with a narrow supporting rail. Generated decorative project marks and casual placeholder copy are not product facts and are intentionally not reproduced. The supplied user feedback takes precedence on portrait scale, language tone, and mobile density: use the original OC art only as small credited accents, professional factual copy, and no picture frame around Osurea.
